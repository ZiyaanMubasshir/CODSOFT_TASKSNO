# CODSOFT Java Development Internship

This repository contains the Java tasks I completed during my CodSoft internship.

## Task 1 - Number Game

This is a simple number guessing game made using Java.

## Features

- Generates a random number between 1 to 100.
- Takes input from the user.
- If the guess is lower / higher than the generated number it provides feedback.
- Continues until the correct number is guessed and code exits.

## Task 2 - Student Grade Calculator
A simple calculator which calculates the grades and marks of students made using Java.

## Features

- Takes inputs of marks according to subjects from the user.
- Calculates the total marks.
- Finds percentage.
- Grades accordingly.
